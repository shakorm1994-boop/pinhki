# پینه‌کی آنلاین — مرحلهٔ اول (لابی عمومی)

این بسته، پایهٔ فنی لابی عمومی را آماده می‌کند: چهار بازیکن واقعی به صف عمومی می‌روند؛ پس از جمع شدن چهار نفر، یک اتاق ساخته می‌شود و صندلی/تیم هر نفر اعلام می‌شود. تیم‌ها به شکل صندلی‌های ۰ و ۲ در برابر ۱ و ۳ هستند.

## نکتهٔ مهم و شفاف

**این نسخه هنوز بازیِ نوبتی را بین چهار مرورگر همگام نمی‌کند.** این مرحله فقط صف عمومی، ساخت اتاق و تخصیص صندلی/تیم را آماده می‌کند. موتور بازی موجود در `index.html` نگه داشته شده و قوانین آن عمداً بازنویسی نشده‌اند. قبل از آنلاین شدن کامل، باید موتور بازی از حالت تک‌مرورگر/ربات جدا شود، کنترل نوبت‌ها سمت سرور اعتبارسنجی شود و فقط دستِ خصوصی هر بازیکن به همان بازیکن ارسال شود. ادعای آنلاین کامل یا حفظ کامل قوانین در مرحلهٔ اول درست نیست.

## فایل‌ها

- `index.html` — نسخهٔ فعلی بازی؛ موتور و قوانین موجود حفظ شده‌اند.
- `server/server.js` — سرور Node.js و Socket.IO برای صف عمومی و اتاق‌ها.
- `server/package.json` — وابستگی‌ها و فرمان اجرا.
- `online-lobby.js` — اسکریپت رابط کاربری برای اتصال به صف عمومی.

## گام ۱ — انتشار فرانت‌اند در GitHub Pages

1. در مخزن GitHub بازی، فایل `index.html` را در ریشهٔ مخزن قرار بده.
2. فایل `online-lobby.js` را نیز در همان ریشه بارگذاری کن.
3. در `index.html` نزدیک انتهای فایل، پیش از `</body>`، باید اسکریپت لابی بارگذاری شود. این بسته آن را در نسخهٔ `index.html` اضافه کرده است.
4. بعد از بارگذاری فایل‌ها، در Settings → Pages، شاخهٔ `main` و پوشهٔ `/(root)` را انتخاب کن.

## گام ۲ — انتشار سرور لابی

می‌توانی پوشهٔ `server` را به یک مخزن GitHub جداگانه بفرستی و آن مخزن را در یک میزبان Node.js مانند Render به صورت Web Service منتشر کنی.

- Root Directory: `server`
- Build Command: `npm install`
- Start Command: `npm start`

پس از انتشار، نشانی HTTPS سرور را بردار.

## گام ۳ — تنظیم نشانی سرور

در `online-lobby.js` مقدار `SERVER_URL` را پیدا کن و `https://YOUR-SERVER.onrender.com` را با URL واقعی سرور جایگزین کن؛ نمونه: `https://your-service.onrender.com`.

## گام ۴ — آزمایش لابی

برای تست واقعی صف، چهار مرورگر/دستگاه لازم است. هرکدام بازی را باز می‌کنند، «بازی آنلاین» را می‌زنند و وارد صف می‌شوند. با تکمیل چهار نفر، اتاق و جایگاه تیم نمایش داده می‌شود.

## مرحلهٔ بعد برای بازی کامل

1. استخراج قوانین و توابع بازی به ماژول مستقل بدون تغییر در منطق قوانین.
2. اجرای موتور بازی به‌صورت authoritative روی سرور.
3. ارسال کارت‌های دست فقط به بازیکن مربوطه و ارسال وضعیت عمومی میز به همه.
4. پیاده‌سازی رویدادهای `draw`, `take-all`, `meld`, `discard` با اعتبارسنجی سمت سرور.
5. تست خودکار قوانین موجود در راهنمای بازی و مقایسهٔ امتیازها با نسخهٔ فعلی.
6. افزودن اتصال مجدد، خروج بازیکن، مدیریت AFK و محدودیت نرخ پیام‌ها.

## امنیت

این سرور در حال حاضر یک نمونهٔ اولیهٔ لابی است. برای انتشار عمومی، CORS را به دامنهٔ GitHub Pages خود محدود کن و قبل از اضافه کردن بازی واقعی، اعتبارسنجی سمت سرور، محدودیت نرخ و سیاست‌های ضدتقلب را کامل کن.
